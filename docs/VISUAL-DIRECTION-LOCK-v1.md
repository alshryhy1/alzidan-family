## المعادلة الملزمة

```text
Visibility Specification
        ↓
يحدد ما يُسمح بعرضه
        ↓
Composition / Visual Direction
        ↓
يجعل المسموح به تجربة عائلية غنية
```

> **المواصفة المعمارية لا تفرض شكلًا فقيرًا.**  
> Visibility ≠ واجهة باهتة.

---

## لغة المنتج البصرية

| عنصر | القاعدة |
|------|---------|
| الألوان | **أخضر عميق + ذهبي + كريمي** |
| الزخارف | زخارف عائلة الزيدان = **هوية** · ليست تزيينًا عشوائيًا |
| العناوين | Hero / عنوان كبير / تكوين واضح · لا عناوين صغيرة وحقول متراصة |
| الشاشات | لكل شاشة **شخصية ومشهد مختلف** · لا نسخ Composition بأسماء مختلفة |
| الحركة/المشهد | الإحساس بالمشهد أهم من كثرة المعلومات |

## شخصيات الشاشات الأربع

| الشاشة | التركيب | الشخصية |
|--------|---------|---------|
| الرئيسية | لحظة | حضور عائلي + بحث قوي + **لحظة واحدة** · ليس Feed |
| البحث | نتيجة | سريع وواضح · إخراج عائلي · **ليس Admin-list** |
| لقاء الشخص | حضور | فاخر للشخص · **ممتاز بلا Person Photo** · بلا اختراع صورة لمحمد |
| المناسبة | مشهد | حدث عائلي حي · الأغنى عند توفر مادة حقيقية |

## ممنوع تثبيتًا

- صور أشخاص مولَّدة/افتراضية تُعامل كبيانات حقيقية في v1  
- Person Photo / Avatar كعمود فقري للشاشة  
- Wireframe أبيض باهت  
- صفحات بيانات / Admin-list UI / لوحة إعدادات تقنية  
- فراغات كبيرة لمجرد ملء الشاشة  
- معلومات لم يسمح بها Visibility Spec  
- كشف عناصر نسائية / جوال / صلة غير مسموحة على الأسطح العامة  
- **«تواصل مع [الشخص]» دائم** أو شات  
- **كتلة مساعدة مندوب / أنواع طلب** داخل لقاء الشخص كقسم ثابت  
- عنوان **«سياسة الظهور»** أو مفتاح/جملة «ظاهر/غير ظاهر في البحث» على الحساب  
- افتراض حالة Visibility في الـComposition بلا قرار منتج  
- «سجّل لترى المزيد» المزعج · احذف المخفي بصمت  
- **كتلة مساعدة مندوب** داخل اللقاء  
- **تواصل دائم** مع الشخص  

### تفاعل مسموح (سياقي فقط)

عند مناسبة/حالة قائمة: **هنّئ · بارك · عزِّ · ادعُ** — ينتهي بانتهاء الحالة.

### ثلاث Compositions إلزامية للقاء الشخص

1. **زائر** — عام مسموح فقط · بلا كشف مخفي  
2. **عضو يشاهد غيره** — صلة · تسلسل · عائلة ظاهرة · مناسبات تجمعكما · تفاعل سياقي  
3. **صاحب الحساب (Self)** — تجربته · **بلا** لوحة «ظهور حسابك» افتراضيًا  

نفس الثراء البصري في الثلاثة · ليست شاشة واحدة بنصوص متبدلة فقط.

---

## لقاء الشخص — قيد المرحلة القادمة

عند الرسم التالي لـ«لقاء الشخص»:

1. الإبقاء على **نفس مستوى الثراء** (أخضر/ذهبي/كريمي/Hero/زخارف).  
2. **بدون** اختراع صورة لمحمد.  
3. **بدون** أي عنصر خارج Visibility (زائر ≠ عضو ≠ self).  
4. النجاح البصري يجب أن يثبت **حتى بدون صورة شخص**.
