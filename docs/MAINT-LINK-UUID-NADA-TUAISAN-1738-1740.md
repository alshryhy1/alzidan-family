1. Hard Refresh لـ `/pages/admin.html` (Cmd+Shift+R).
2. الإدارة → **⚙ أدوات الصيانة** (`#module=tools`).
3. شغّل أولًا البطاقة **… — معاينة** (قراءة فقط).
4. راجع الأعمدة:
   - `proposed_father_name` / `proposed_father_person_id` لـ 1738 و 1739 يجب أن تشيران إلى 1739 و 1740.
   - لـ 1740: إن كان `apply_status = ready_exact_unique` فالمرشح فريد وآمن.
   - إن كان `stop_no_exact_match…` أو `stop_ambiguous…` **لا تشغّل APPLY على 1740** — انسخ `nada_exact_candidates` و `nada_leaf_candidates_info_only` وراجع يدويًا.
5. بعد موافقة صريحة: شغّل البطاقة **… — APPLY**.
6. نتيجة APPLY تعيد الصفوف الثلاثة مع `link_ok` و`father_name`. المسار عبر UUID يجب أن يقرأ: نداء → طعيسان → حمد → محمد (إن اكتمل ربط 1740).
